# Bookvnts - Event Booking System

Bookvnts is an event ticketing network. It unites collegiate cultural fests, collegiate pro-nites, and student creator communities across premier universities nationwide.

## 🚀 Features
- **Event Discovery:** Browse and search for various events (Concerts, Movies, Comedy Shows, Sports, etc.).
- **Dynamic Search:** Fully functional real-time search engine for artists, bands, venues, and event types.
- **Organizer Portal:** Built-in dashboard for college fest committees to host events and list tickets seamlessly with zero gateway commission.
- **Secure Ticketing:** Digital QR entry protocols for secure, authentic, and transparent event passes.
- **Responsive UI:** A stunning, fully responsive "Luminous Electric" frontend theme using Bootstrap 5.3.3 and modern typography.

## 🛠️ Tech Stack
- **Frontend:** HTML5, Vanilla CSS3 (Custom Variables), JavaScript, Bootstrap 5.3.3
- **Backend:** PHP
- **Database:** MySQL

## 💻 Installation (Local Development)

1. Clone the repository into your local server environment (e.g., inside the `htdocs` directory if using XAMPP).
   ```bash
   git clone https://github.com/Xandriel-2005/EventBookingSystem.git Bookvnts
   ```
2. Start your Apache and MySQL servers.
3. Open phpMyAdmin (`http://localhost/phpmyadmin`) and create a new database.
4. Import your `.sql` database file into the new database.
5. Update the database connection credentials inside `config/config.php` to match your local setup.
6. Navigate to `http://localhost/Bookvnts` (or your specific path) in your browser.
